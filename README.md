A program that writes one original funny one-line resignation letter to
`/output/entry.txt`, for the make.fun bounty
[The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

Run it with `python3 main.py`; it writes the resignation line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
